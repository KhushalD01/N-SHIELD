USAI - Nagpur City Command Center

AI-Powered Urban Safety Intelligence Nagpur City Digital Twin

1. Executive Summary & Vision

USAI is an advanced Urban Safety Intelligence & 3D Command Center platform built for Nagpur City. It merges spatial risk modeling, CCTV blind spot detection, AI police force deployment, public event impact forecasting, and Explainable AI (XAI) into an interactive digital twin.

2. System Architecture & Tech Stack

  • Next.js 16 (App Router) + React 19 + TypeScript
  • Tailwind CSS v4 (Futuristic Dark UI Theme)
  • Google Maps JavaScript API + Mapbox GL 3D Digital Twin
  • Deck.gl GPU Heatmaps & Sensor Overlay Layers
  • Web Audio API Synthesized Alarm Engine

4. Algorithmic Risk & Deployment Engines

Risk Score Calculation Formula:

RiskScore = min(100, Round((IncidentLoad * 0.38 + TimeFactor * 0.27 + CCTVDeficit * 0.22 + LightingDeficit * 0.13) * 100))

Required Patrol Allocation Formula:

RequiredPatrols = max(2, Round((Population / 50000) + (RiskScore / 15) + (CrimeVelocity / 20)))

5. REST API Endpoints

  • GET /api/incidents - Query incidents filtered by zone, severity, or type.
  • GET /api/cctv - CCTV surveillance network status and coverage analysis.
  • GET /api/zones - Complete sector metadata and coordinates.
  • GET /api/news - Live real-time Nagpur crime and urban safety news feed.
